# Essential Cam

Essential Cam is a simple iPhone camera app focused on giving photographers direct access to essential capture controls while keeping the interface straightforward.

The goal is to capture clean, editing-ready images without adding advanced image processing or artificial intelligence features.

## Current milestone

The first milestone establishes the camera foundation and displays the live camera preview in the app UI. It includes camera-device discovery, capture-session management, photo-capture abstractions, preview rotation handling, and camera authorization status.

## Planned direction

Future iterations will add essential manual controls such as ISO, exposure, focus, white-balance temperature, and tint, followed by support for capturing images suitable for editing in external photography tools.

## Technology

- Swift
- SwiftUI with UIKit integration for the camera preview
- AVFoundation
- Swift Concurrency
